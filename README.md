A tiny program (`main.py`) that writes exactly one word to `/output/entry.txt`: **GeePeeTea** — the word grandma texts about AI after mishearing ChatGPT's last letter and turning GPT into tea. Warm, a little baffled, funny in a single word, and tied specifically to AI. The output is deterministic: 9 characters, 9 bytes, no spaces, no punctuation, no trailing newline, identical on every run.
